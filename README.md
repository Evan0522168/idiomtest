成語學習助手 (Chengyu Assistant)
【專案簡介】
這是一個免安裝、開箱即用的單頁面成語學習工具。
專為成語複習與測驗設計，支援自訂當次練習清單，
內建超過 200 個常見與高階成語及詳細解釋。
【主要功能】
自訂當次練習清單
可以在輸入框中自由貼上當次想複習的成語清單。
系統會自動解析並僅針對「當次輸入」的成語進行練習。
內建完整成語資料庫，無需連線或設定資料庫。
Flashcard（單字卡模式）
提供「會了」、「有印象」、「忘記了」三個評估按鈕。
點選「有印象」或「忘記了」會立刻顯示正確成語解釋。
跑完一輪後，自動生成剔除「會了」的新清單，並支援一鍵複製。
Quiz（選擇題測驗模式）
每題隨機抽出 1 個正確解釋與 3 個干擾選項。
可自訂題數（10 / 20 / 30 / 50 / 100 / 全部）。
隨機出題，測驗結束後自動計算得分與正確率。
測驗過程完全不會修改或刪除你的原始清單。
【使用方式】
直接使用任何瀏覽器（Chrome, Edge, Safari, Firefox 等）
開啟 html 檔案即可開始使用，無需安裝任何軟體或套件。
